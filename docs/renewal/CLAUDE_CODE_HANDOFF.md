# 덕홍닷컴 리뉴얼 — Claude Code 참고용 핸드오프

> **용도: 참고 전용.** 이 문서는 현재 미리보기의 의도와 제약을 전달하기 위한 기록이다. 문서 내용만으로 기존 운영 사이트의 코드·도메인·배포 환경을 수정하거나 배포하지 않는다. 운영 반영은 별도의 명시적 지시와 검토를 거친다.

## 1. 프로젝트 개요

현재 작업물은 **김덕홍 제주특별자치도의회 의원의 의정활동·정책·현장 기록 사이트 미리보기**다. 이전 선거 캠페인 소스를 분석해 만들었지만, 최종 방향은 선거 홍보가 아니다. 따라서 후보·투표·당선·유세·지지 호소 등 선거 시점의 언어와 그래픽을 사용하지 않는다.

| 항목 | 현재 상태 |
|---|---|
| 작업 프로젝트 | `/home/ubuntu/dukhong-renewal` |
| 성격 | 정적 프런트엔드 미리보기 |

| 운영 반영 | **미수행** — 기존 운영 사이트에 영향 없음 |

## 2. 가장 중요한 제약

이 사이트는 현직 의원의 공적 활동을 기록하는 공간이다. 화면 문구는 관찰·기록·책임·현장 중심으로 유지하고, 캠페인 슬로건처럼 과장된 설득 문법으로 바꾸지 않는다. 방문자에게 보이는 텍스트는 **한국어가 기본**이며, 영문 헤드라인·영문 메타데이터·영문 사진 캡션을 장식 용도로 추가하지 않는다.

이미지는 사용자가 제공한 의정활동 사진과 기존 소스에 포함된 실제 현장 사진만 쓴다. 생성 이미지, 임의 스톡 이미지, 출처가 불명확한 지도·추상 이미지를 대체재로 넣지 않는다.

> 운영 중인 웹사이트의 원본 소스, 도메인, 서버 설정, 배포 설정을 바꾸지 말 것. 현재 프로젝트는 별도 미리보기다.

## 4. 현재 디자인 시스템

### 색과 재료감

기본 화면은 웜 화이트(`--paper`)이며, 먹색 텍스트·옅은 회색 기준선·절제된 귤빛(`#d96f24`)을 사용한다. 귤빛은 큰 감정적 배경이 아니라 섹션 번호, 기록 표식, 문장부호, 핵심 행동에 제한한다.

헤더와 푸터의 `basalt-mark`는 한글 초성 **ㄷㅎ**을 현무암 블록처럼 추상화한 브랜드 심볼이다. 이를 일반적인 원형 아이콘이나 텍스트 로고로 대체하지 않는다.

### 그리드와 키비주얼

데스크톱에서는 `--page-x`를 공통 여백으로 사용하고, 주요 영역은 12열 그리드로 정렬한다. 키비주얼은 여러 사진 카드가 아니라 **첫 화면 우측의 단일 대형 의정활동 회의 사진**이다. 제목은 좌측에서 의도된 두 줄로 읽혀야 하며, 자동 줄바꿈에 맡기지 않는다.

| 화면 영역 | 정렬 원칙 |
|---|---|
| 헤더·상단 기준선 | `--page-x`와 동일한 좌우 여백 |
| 첫 화면 제목 | 12열 중 좌측 7열, 두 줄 고정 |
| 첫 화면 키비주얼 | 우측 5열, 사진 프레임 상단의 귤빛 상태선 |
| 본문 제목·설명 | 제목 7열, 설명 4열의 분리된 읽기 흐름 |
| 활동 기록 사진 | 키비주얼 아래의 기록 근거로만 사용 |
| 모바일 | 1열 재배치, 제목은 의도된 두 줄, 키비주얼은 전체 폭에 가깝게 |

## 6. 현재 정보 구조

첫 화면은 `현장에서 듣고, 의정으로 답합니다.`라는 제목과 단일 키비주얼로 시작한다. 그 아래에는 소개·공직 경력, 의정활동의 원칙, 6개 의정 과제, 실제 현장 사진과 활동 기록, 마무리 문구가 차례로 배치되어 있다. 상단 메뉴는 `소개`, `의정 과제`, `활동 기록` 앵커 이동이다.

현재 의정 과제와 활동 기록은 정적 예시 콘텐츠다. 이후 실제 보도자료·정책 추진 현황으로 교체할 경우, 날짜·장소·기록 구분을 함께 명시해 공적 아카이브 구조를 강화한다.

## 7. 실행 및 검증 방법

```bash
cd /home/ubuntu/dukhong-renewal
pnpm install
pnpm dev
```

코드 변경 뒤에는 아래 검사를 모두 실행한다.

```bash
pnpm check
pnpm build
```

검증할 때는 최소한 데스크톱 1280×720과 모바일 375×812에서 다음을 확인한다.

1. 첫 화면에 단일 대형 키비주얼이 명확히 보이는지 확인한다.
2. 제목이 임의로 줄바꿈되지 않고, 키비주얼·본문·푸터가 공통 좌우 기준선에 맞는지 확인한다.
3. 영어가 방문자 화면에 새로 노출되지 않았는지, 실제 사진만 쓰는지 확인한다.
4. 선거 캠페인으로 해석될 문구나 CTA가 생기지 않았는지 확인한다.
